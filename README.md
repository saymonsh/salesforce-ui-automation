# Salesforce UI Automation

פרויקט זה הוא כלי אוטומציה לביצוע פעולות ב-Salesforce, הכולל ממשק משתמש (GUI) שנכתב ב-Python.
הכלי מאפשר ביצוע פעולות אוטומטיות כגון קליטת מועמדים, מילוי נוכחות, ויצירת דיווחים על בסיס קבצי אקסל.

## תכונות עיקריות

*   **ממשק גרפי נוח**: נבנה באמצעות ספריית `pyvisual` לשימוש קל ואינטואיטיבי.
*   **אוטומציה לדפדפן**: שימוש ב-Selenium לביצוע פעולות ב-Salesforce.
*   **תמיכה במספר תהליכים**:
    *   **קליטה ודיווח (Type 1)**: התחברות, קריאת נתונים מאקסל, ויצירת פעילויות/דיווחים בהתאם.
    *   **הוספת מועמדים (Type 2)**: צירוף אוטומטי של מועמדים לתוכנית.
    *   **מילוי נוכחות (Type 3)**: סימון נוכחות גורף למשתתפים.
*   **ניהול הגדרות**: שמירת סיסמאות ופרטי התחברות בצורה נוחה.

## סקירת קבצים

### קבצי ליבה
*   `app.py`: הקובץ הראשי שמנהל את האפליקציה והלוגיקה.
*   `main_ui.py`: אחראי על עיצוב החלון הראשי.
*   `run_app.bat`: סקריפט להרצת האפליקציה בווינדוס.

### אוטומציה ולוגיקה
*   `login.py`: לוגיקה ראשית לחיבור ועיבוד תיקים.
*   `actions.py`: ספריית פונקציות לביצוע פעולות ב-Salesforce (חיפוש, יצירה וכו').
*   `add_candidats.py`: תהליך הוספת מועמדים.
*   `attendance_filling.py`: תהליך מילוי נוכחות.

### הגדרות
*   `parameters.py`: שומר את הגדרות המערכת (שם משתמש, URL וכו').
*   `settings_ui.py`: ממשק לעריכת ההגדרות.

## התקנה והרצה

1.  ודא שמותקן Python במחשב.
2.  התקן את התלויות הנדרשות (מומלץ בתוך סביבה ווירטואלית).
3.  הרץ את `run_app.bat` או את `app.py` ישירות.
